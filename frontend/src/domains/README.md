# Frontend Domains

Domain modules own V-KPI product behavior and UI composition for a business area. New feature code should land here instead of adding more logic to `frontend/src/components/vkpi/pages`.

Each domain should keep page shells thin and place reusable behavior in domain components/hooks/contracts.

Initial domains:

- `dashboard`
- `data-quality`
- `intelligence`
- `market`
- `kol`
- `projects`
- `products`
- `attribution`
- `settings`
- `repair`
