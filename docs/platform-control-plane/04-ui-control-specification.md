# 04｜页面与控制细则

## 1. 统一交互规范

三套控制台共享设计系统、身份和审计回执，但使用不同颜色标识与 URL 根路径：

- 母控制台：`/platform/*`，页面顶栏持续显示“平台控制面”。
- 公司控制台：`/company/*`，持续显示公司名、区域和当前环境。
- 用户控制台：`/me/*`，持续显示当前工作区，可显式切换公司。
- 支持/紧急会话：全屏固定警示条，显示目标公司、权限、剩余时间和退出按钮。

任何页面不得仅依赖前端权限隐藏。页面加载时由 `/capabilities` 返回服务端计算后的可见动作；提交时服务端再次判断。

## 2. 动作与确认等级

| 等级 | UI 控制 | 服务端控制 | 示例 |
|---|---|---|---|
| L0 | 无确认 | 只读权限、访问审计按需 | 查看列表、健康状态 |
| L1 | 保存提示、可撤销 | 乐观锁、普通审计 | 改名称、个人主题 |
| L2 | 明确确认、填写原因 | 权限 + 幂等 + 审计回执 | 邀请成员、删除记忆 |
| L3 | 影响预览、输入目标、MFA | Step-up + 状态机 + 强审计 | 暂停公司、切换模型 |
| L4 | 双人批准、维护窗口、回滚计划 | 审批令牌 + 强审计 + 自动撤销 | 删除公司、全局发布、Break-glass |

所有 L2–L4 操作完成后显示：操作状态、实际影响、操作者、操作 UID、审计回执 UID、可撤销截止时间或“不可撤销”说明。

## 3. 公共页面结构

### 3.1 列表页

必须包含：

- 服务端分页、排序、组合筛选和保存视图。
- 当前作用域说明，例如“仅当前公司 / 当前区域 / 最近 30 天”。
- 列配置与导出权限分离；看得见列表不代表可以导出。
- 批量动作先显示预计影响数和无法处理项。
- URL 保存筛选条件，返回页面不丢上下文。
- 空态区分“没有数据”“无权限”“模块未购买”“功能被关闭”“加载失败”。

### 3.2 详情页

建议使用：概览、配置、用量、运行、审计五类 Tab。每个字段标明来源：平台默认、套餐、公司覆盖、项目策略或个人偏好。

### 3.3 长任务

开通、迁移、发布、索引、导出、删除等均返回 Operation：

- 阶段、百分比、开始/更新时间、执行者。
- 已完成项、正在执行项、等待原因、可重试项。
- 日志摘要和安全脱敏的错误代码。
- 取消、重试、回滚按钮是否可用及原因。
- SSE 优先，断线后可从最后事件继续；轮询为降级方案。

## 4. 母控制台页面

### 4.1 `/platform/overview` 平台总览

| 区域 | 内容 | 控制 |
|---|---|---|
| 租户 | active/trial/grace/suspended 数量、开通失败 | 点击进入过滤列表 |
| 商业 | MRR/ARR、席位、额度使用、欠费 | 财务角色可见；正文业务数据不可见 |
| 运行 | 区域健康、服务错误率、队列积压、Worker 漂移 | 告警可确认/指派，不在卡片直接重启 |
| AI | 模型就绪、Provider 失败、Token、成本、预算阻断 | 精确模型维度，不能只显示供应商总绿灯 |
| 发布 | 当前版本、灰度批次、失败租户、回滚状态 | 发布动作进入专页 |
| 风险 | 高危权限变更、紧急会话、敏感导出 | 安全角色优先展示 |

总览卡片必须注明时间窗口、数据更新时间和数据完整性；缺数据不能显示为 0。

### 4.2 `/platform/organizations` 公司列表

字段：公司名、UID、状态、套餐、模块数、主区域、部署模式、Owner、席位、账期用量、版本、最近健康、创建时间。

筛选：状态、套餐、模块、区域、版本、用量阈值、告警、试用到期、欠费。

动作：

- 新建公司（L3，激活为 L4）。
- 修改标签/商务负责人（L1）。
- 暂停/恢复（L3）。
- 停用（L3/L4）。
- 计划删除（L4）。
- 申请支持访问（单独流程，不提供“一键进入”）。

批量暂停和批量删除首版禁止。

### 4.3 `/platform/organizations/new` 开通向导

| 步骤 | 输入 | 即时校验 |
|---|---|---|
| 公司 | 名称、Slug、法定名称、行业标签 | Slug 唯一、域名格式 |
| 商业 | 套餐、模块、席位、账期、试用/信用 | 模块依赖、配额和价格预览 |
| 部署 | 区域、共享/专属、发布渠道 | 区域容量、数据驻留、版本兼容 |
| AI | 模型策略、平台 Key/BYOK、降级 | 精确模型就绪、数据策略、预计成本 |
| 安全 | 首位 Owner、MFA、域名/SSO | Owner 唯一、域名冲突 |
| 预检 | 数据库、存储、队列、密钥、健康 | 每项可重试、失败可清理 |
| 激活 | 最终差异、预计月费、风险、审批 | L4 双人批准 |

向导可保存草稿。刷新或失败后从状态机继续，不能重复创建资源。

### 4.4 `/platform/organizations/{uid}` 公司详情

Tab：概览、生命周期、套餐权益、管理员、部署、AI 路由、用量成本、集成、审计、支持访问。

关键控件：

- 状态卡显示实际允许行为，不只显示状态文字。
- 权益页同时显示套餐值、覆盖值、有效值、来源和到期日。
- 部署页不展示密钥，只展示密钥引用、版本和健康。
- 成本页将供应商成本、客户计费用量和预计毛利分开。
- 审计页默认不展示业务正文，只展示动作和资源引用。

### 4.5 `/platform/plans` 与 `/platform/modules`

套餐字段：代码、版本、价格、账期、席位、模块、用量、超额、支持等级、适用区域、状态。

模块字段：模块版本、依赖、能力、权限、计量项、数据等级、区域、模型、审计和回滚支持。

控制：

- 已被订阅的套餐版本不可原地改写，需复制新版本。
- 删除模块前列出所有租户和依赖模块；先 deprecated，后 retired。
- 变更预览展示哪些公司会增加/失去能力。
- 临时权益覆盖必须输入原因和到期，默认最长 30 天。

### 4.6 `/platform/regions` 与部署

区域列表：司法辖区、状态、容量、数据库、缓存、队列、对象存储、模型出口、版本、复制延迟、最近 DR 演练。

区域详情：

- 不允许在普通编辑表单修改底层资源标识。
- 停止接收新租户与关闭区域是两种动作。
- 区域迁移必须选择目标、维护窗口、验证清单和回滚截止。
- 迁移过程中显示写入冻结、复制校验、切换、回查和旧区清理阶段。

### 4.7 `/platform/providers` 与 `/platform/models`

Provider 列表：账户所有权、区域、状态、密钥版本、最近探测、失败率、成本、数据处理标签。

模型目录：精确模型 ID、模态、上下文、价格版本、区域、数据政策、就绪状态、退役日期。

动作：添加账户（L3）、轮换密钥（L4）、探测（L1）、停用（L3）、发布模型策略（L3）、全局禁用模型（L4）。

模型切换预览：受影响公司/功能、过去 7 天请求量、成本变化、质量证据、Fallback、灰度和回滚阈值。

密钥永不回显；“已配置”必须来自实际 Secret 引用健康，而不是仅检测环境变量。

### 4.8 `/platform/quotas` 与 `/platform/costs`

视图：平台 → 区域 → 公司 → 模块 → 项目/用户逐层下钻。

指标：请求、Token、对象数、抓取、存储、并发、供应商成本、计费用量、未归属成本。

控制：

- 配额模板变更显示受影响租户。
- 80% 提醒、90% 升级、100% 按套餐硬停或超额。
- 预算覆盖必须有期限和审批。
- 调账创建正/负调整事件，不修改历史用量。
- 对账页列出供应商账单差异和不可归属项。

### 4.9 `/platform/flags` 与 Kill Switch

Flag 字段：Owner、环境、规则范围、变体、比例、开始/结束、依赖、到期、状态。

规则优先级可视化，提供“在给定公司/用户/版本上求值”的调试器，并返回来源链。

控制：

- 全局 Flag 变更 L4；单公司灰度 L2/L3。
- 规则必须有 Owner 和过期复核日。
- Kill Switch 独立页面，启用 L3/L4，必须写事故号。
- Flag 关闭不自动取消已运行的不可中断任务；页面必须说明停止语义。

### 4.10 `/platform/releases`

发布制品显示：Git SHA、镜像摘要、SBOM、签名、迁移清单、配置摘要、测试和安全证据。

发布流程：选择渠道/区域 → 影响预览 → 维护窗口 → 审批 → 内部租户 → 5% → 25% → 100%。

页面持续显示错误率、P95、队列、Provider 失败、预算异常和数据校验；达到阈值自动暂停。回滚按钮要求选择代码、配置和数据库兼容策略，不允许盲目回滚破坏性迁移。

### 4.11 `/platform/runtime`

视图：服务、实例、Worker、Scheduler、队列、数据库、缓存、对象存储、外部供应商。

每个健康状态必须有证据时间、版本、信任来源和依赖。重启、清队列、重放死信等动作分离，均显示影响范围。清空队列默认禁止；重放需租户和幂等检查。

### 4.12 `/platform/audit`

筛选：公司、区域、环境、Actor、有效 Actor、动作、资源、结果、风险等级、请求/追踪、支持/紧急会话、时间。

审计详情：前后值哈希、决策 ID、策略版本、认证强度、审批、原因、IP/设备摘要、发布版本。敏感字段按角色脱敏；导出审计本身再写审计。

### 4.13 `/platform/access/support` 与 `/break-glass`

支持访问表单：工单、目标公司、资源、动作、理由、TTL、客户同意。默认只读。

Break-glass：事故号、精确范围、15–60 分钟 TTL、Step-up、双人批准、实时通知。活动会话页面显示剩余时间和逐请求事件；用户不能延长自己的会话。结束后必须填写复盘结果。

## 5. 公司管理控制台页面

### 5.1 `/company/overview`

卡片：成员/席位、部门、活跃项目、配额、运行中任务、失败工作流、知识同步、待审批、安全事件和套餐限制。

公司总览只展示本公司。套餐限制旁提供“联系平台/申请升级”，不能直接打开未购买能力。

### 5.2 `/company/departments`

左侧部门树，右侧详情。字段：名称、代码、上级、负责人、成员、子部门、默认项目策略、成本中心。

动作：新建、移动、合并、停用、删除。移动和合并显示受影响角色、项目、知识和预算；有资源的部门不可直接删除，需交接。

临时团队单独页面，带到期时间，不混入正式部门树。

### 5.3 `/company/members`

字段：成员、状态、部门、角色、项目数、MFA、最后活跃、会话数、邀请/离职时间。

动作：邀请、重发/撤销邀请、改部门、绑定角色、暂停、恢复、离职交接、撤销会话。不能删除最后一名 Owner；管理员不能授予自己不可委派的角色。

成员详情不向普通管理员展示私人 AI 对话、个人记忆正文或完整 IP。

### 5.4 `/company/roles`

左侧系统/自定义角色，右侧动作矩阵和范围。创建角色时从模板复制，系统展示危险权限和不可组合权限。

发布新版本前展示受影响成员和资源；权限缩减立即生效并撤销旧会话，权限扩大可要求审批。删除角色前必须迁移所有绑定。

### 5.5 `/company/data-policies`

配置：数据分类、默认项目可见性、敏感导出、外部模型、保留、共享、下载水印、设备/MFA 条件。

提供策略模拟器：选用户、动作、资源和上下文，展示允许/拒绝与来源链。禁止直接编辑低层 JSON 作为唯一界面。

### 5.6 `/company/projects`

字段：项目、部门、Owner、可见性、数据等级、成员、模块、预算、最近活动、状态。

动作：新建、模板化、改范围、归档、恢复、交接 Owner。跨部门共享必须选择精确成员/角色和期限；restricted/L2+ 项目不能一键公开。

### 5.7 `/company/knowledge`

层级：知识空间 → 来源 → 文档 → 同步/索引运行。

字段：归属项目、数据等级、ACL、来源类型、同步频率、文档数、失败数、最后同步、模型/区域。

动作：连接来源（L2/L3）、测试、同步、暂停、重建索引、删除。连接凭证只显示引用状态。搜索测试器必须以当前操作者权限返回结果，并展示引用来源。

### 5.8 `/company/agents`

列表：智能体、Owner、版本、状态、模型策略、工具、记忆策略、自主等级、使用者、近 7 天运行/成本/成功率。

编辑器分为说明、输入输出、模型、工具、知识、记忆、行动、评测、授权。发布前必须通过权限、成本、注入、敏感数据、质量和回滚检查。

自主等级：

- A0：只回答。
- A1：生成行动草稿，用户确认后执行。
- A2：低风险动作自动执行，高风险审批。
- A3：限定工作流内自主运行，严格预算和停机开关。

首发不提供无边界自主执行。

### 5.9 `/company/workflows`

列表：工作流、版本、触发器、Owner、发布范围、运行数、失败率、成本、待审批。

编辑器使用版本草稿；节点显示所需权限、输入/输出、重试、超时、幂等、成本和数据等级。发布预览列出新增工具、密钥、模型和权限。运行页可取消、重试安全节点、处理死信，不能跳过必需审批。

### 5.10 `/company/usage`

按部门、项目、用户、模块、模型和时间下钻。展示套餐用量、供应商成本可选视图、公司子预算、异常增长和未归属比例。

财务角色可看聚合金额，不自动获得业务正文。部门管理员只看本部门。导出遵守数据和财务双重权限。

### 5.11 `/company/security`

配置：域名验证、SSO、MFA、会话时长、IP/设备策略、服务账号、保留、导出、应用连接、支持访问同意策略。

修改 SSO/MFA 前要求预检和恢复管理员；避免错误配置锁死全公司。紧急恢复码离线保存且不在 UI 回显。

### 5.12 `/company/audit`

视图：成员/角色、项目/数据、AI/模型、知识/工作流、导出、登录/会话、平台支持访问。公司审计员可导出本公司日志，不能看到平台内部注释、其他公司或密钥。

## 6. 用户控制台页面

### 6.1 `/me/home`

卡片：今日任务、待审批、运行中、失败待处理、最近项目、AI 建议、通知和配额。卡片只来自当前工作区；跨公司不混合，除非专门的安全聚合页只显示数量。

### 6.2 `/me/tasks`

视图：分配给我、我创建、自动化、等待审批、已完成。每项显示项目、阶段、来源、截止、运行状态、成本/用量和可执行动作。

后台任务使用分阶段进度，基础结果可先展示，视频/评论/受众/QA 等后续阶段继续运行；不能只显示长时间空白等待。

### 6.3 `/me/projects`

视图：我负责、我参与、共享给我、收藏、最近。项目卡说明为什么可见（Owner/成员/部门/公司公开），并明确数据等级。无权资源返回统一不可用，不泄露内容。

### 6.4 `/me/data`

保存查询、数据集、导出任务和最近访问。每项显示来源、更新时间、数据等级、项目和权限。导出前预估行数、敏感字段、配额和到期时间。

### 6.5 `/me/assistant`

布局：会话列表、对话、引用/运行侧栏。回复展示使用模型的可理解名称、引用、数据时间、工具调用、运行状态和行动草稿。

用户必须确认记忆候选和真实行动。流式中断可恢复；失败时保留已完成阶段和可重试请求 ID。公司策略禁止的模型或工具不出现在选择器。

### 6.6 `/me/memory`

Tab：候选、已确认、暂停/保留、事件记录。

操作：确认、编辑后确认、拒绝、逐条删除、暂停记忆、导出、删除全部。每条显示来源会话、创建时间、敏感等级、使用范围和最近使用。公司管理员默认不能读取正文。

### 6.7 `/me/notifications`

通知中心含未读/全部、类型、项目和批量已读。偏好支持站内、邮件、IM/Webhook、即时/摘要、免打扰。渠道启用前验证端点；发送失败显示状态和重试，不把“已保存偏好”伪装为“通知已送达”。

### 6.8 `/me/authorizations`

展示公司角色、部门、项目、知识、智能体、工作流和第三方连接授权，以及来源、授予人和到期。用户可申请、放弃可选授权，不能自我批准。

### 6.9 `/me/sessions`

展示当前/其他设备、最近活跃、粗粒度位置、认证强度。支持撤销单个会话、退出其他设备、查看服务账号/第三方连接。修改密码或发现风险时可全量撤销。

### 6.10 `/me/usage`

展示个人请求、Token、分析任务、抓取、存储和配额剩余，按项目/功能解释。若公司不向员工公开金额，则显示单位而不显示供应商成本；不能用不完整归属数据制造精确费用假象。

### 6.11 `/me/preferences`

语言、时区、主题、日期、无障碍、默认项目、允许的默认模型、AI 回答风格。每个设置标注“个人可改”或“由公司管理”。个人设置不能突破公司数据/模型政策。

## 7. 状态、空态与错误态

| 状态 | 页面表现 | 禁止行为 |
|---|---|---|
| 加载 | 骨架 + 作用域占位 | 把旧公司数据留在屏幕上 |
| 无数据 | 说明原因和下一步 | 统一写“暂无数据” |
| 无权限 | 显示需要的能力/申请路径 | 暴露资源内容或其他租户存在性 |
| 未购买 | 显示模块价值和联系入口 | 用升级按钮直接绕过权益 |
| 功能关闭 | 显示 Flag/Kill Switch 原因和预计恢复 | 与无权限混淆 |
| 配额不足 | 显示指标、窗口、重置时间、申请入口 | 只返回未知错误 |
| 降级 | 显示当前可用能力和数据时间 | 把缓存/模拟结果标成实时 |
| 部分成功 | 列成功、失败、可重试项和回执 | 整批显示成功 |
| 冲突 | 展示他人新版本和差异 | 静默覆盖 |

## 8. 可访问性与终端范围

- WCAG 2.2 AA 作为 Web 验收目标。
- 键盘可完成导航、表单、表格和对话；焦点顺序明确。
- 不用颜色单独表达健康、风险和状态。
- 表格提供可读标题、列说明和屏幕阅读器标签。
- 高风险确认不依赖拖动/鼠标手势。
- 母/公司控制台首发以桌面 Web 为主，最小支持 1280px；移动端提供只读监控和审批，不提供复杂配置。
- 用户控制台响应式支持平板和手机；长表格转为卡片/分段视图。

## 10. 全局 UI 验收门槛

- 三套控制台之间不会因前端路由切换而继承错误权限或公司缓存。
- 每个动作都有服务端能力代码和明确风险等级。
- L2–L4 操作全部显示影响预览和审计回执。
- 长任务有真实阶段进度、可恢复状态和失败明细。
- 0、未知、未采集、无权限、未购买、关闭和失败均有不同语义。
- 支持/紧急会话全程有不可隐藏横幅并可立即退出。
- 关键流程通过键盘、屏幕阅读器、窄屏和慢网测试。
