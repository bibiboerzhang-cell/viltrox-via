# V-KPI 智能营销 OS 总体方案(v2 · 严苛版)· 2026-07-03

> v1(度量层→组合管理→创意智能→ActionInbox→规模化)经严苛复审后判定:方向对但不够差异化——
> 那套 CreatorIQ/Grin/Aspire 都有。v2 回答三个问题:凭什么比"平台的平台"聪明、
> 该接入哪些市场信号、除了 KOL 还该"调度"什么经营动作。

## 一、用最严苛标准给 v1 的五条判词

1. **同质化**:ROI 追踪/组合管理/创意分析,国外 KOL SaaS 全有。做完这些=一个还不错的内部版 Grin,不是壁垒。
2. **数据面窄**:只看 KOL/自有账号/竞品提及,等于只看"供给侧的一个切片",没有需求侧信号。
3. **"智能"不可证伪**:5 个技能是 LLM 包装,没有基准、没有回测、没有准确率——说自己聪明但无法被打脸的系统不算智能。
4. **只调度 KOL 动作**:真实营销经营面是 预算/时机/区域/合作形式/定价窗口,平台只闭环了"找人-合作"一条。
5. **没有用足领域逻辑**:Viltrox 是镜头厂。镜头需求=f(机身生态)。这个行业最强的先行指标(新机身发布)在 v1 里一个字没有。

## 二、真正的差异化定位:镜头生态需求智能 + 执行闭环

**不是"KOL 平台",是"品类需求预测机 + 营销执行机"的合体。**
通用 KOL SaaS 永远做不了,因为它不懂:

- 镜头需求曲线 = 各卡口机身保有量 × 新机发布脉冲 × 焦段/价位空缺 × 竞品覆盖
- 369 SKU 产品知识库(已建)+ 卡口/焦段维度 → 需求-供给匹配矩阵
- 触发式战役:Nikon 发新 Z 机身 → Z 卡口镜头需求 90 天窗口 → 自动圈出 Z 生态 KOL(池内已有生态标签数据)→ 出战役建议

## 三、市场信号接入矩阵(按 价值×成本 排序)

### A 级(高价值·低成本·两周内可接)
| 信号 | 用途 | 接入方式 |
|---|---|---|
| **新机身发布日历** | 镜头业最强先行指标:新机=对应卡口镜头需求爆发 | 爬 DPReview/CameraDecision news + 手工维护大事件;落 market_signal |
| **Google Trends(型号级)** | 需求趋势/地区分布,免费 | pytrends,按 SKU 关键词族每日 |
| **Amazon 类目排名+评论速度** | 销量代理信号(自家+竞品) | Apify actor 已有同类;记账闸内 |
| **eBay 二手成交价** | 残值=真实需求的硬指标(相机圈特性) | eBay API 免费档 |
| **YouTube 搜索建议/量级** | 内容需求缺口("viltrox 85mm vs …"没人做=机会) | 免费接口 |
| **竞品签约情报** | 深析已产 competitor_mentions → 升级:谁在持续发竞品=被签了 | 纯聚合已有数据,零新抓 |

### B 级(高价值·需你侧或中成本)
| 信号 | 卡点 |
|---|---|
| **Shopify 订单回流** | 你配 webhook(老话题,度量层基石) |
| **站内价格/促销日历** | 需要你提供促销计划表(或接价格页爬取) |
| **库存/供应链节奏** | 需要 ERP 导出口径(有货才推,断货不烧曝光) |
| **租赁平台热租榜**(Lensrentals 等) | 专业需求先行指标;爬取中等难度 |
| **B&H 价格盒+评论**(已接一半) | reviews 已入库,补价格监测 |

### C 级(观察名单,暂不接)
FCC/专利、海关数据、客服工单情感——价值真但成本/合规先放。

## 四、"智能"的严苛定义:预测台账(Prediction Ledger)

系统每给一个建议,必须落一条**可对答案的预测**:

- 推荐 KOL → 预测「90 天内带来 ≥N 单」→ 到期自动对 GMV 桥答案
- 创意 brief → 预测「用此开头的视频 72h 播放 > 基线 X%」→ 对快照答案
- 市场窗口 → 预测「该 SKU 地区搜索量/销量 30 天 +Y%」→ 对 Trends/排名答案

**准确率仪表公开挂在 Dashboard**:系统整体命中率、分模型命中率、分场景命中率。
错的预测 → 写入记忆层的"反例"并降低同类建议权重。
这是"越用越聪明"的可证伪实现——也是对外售卖时唯一有说服力的智能证据。
(基建全有:outcomes 表、feature_snapshot、event_ledger、evals 框架——缺的只是把它们串成台账。)

## 五、调度面扩展:从 KOL 动作到经营动作

Action Inbox 2.0 的动作类型从"补档/联系/重试"扩到:

1. **战役级**:新机身触发的窗口战役(圈人+brief+预算包)
2. **预算级**:月度组合再平衡(砍/加注,带 P&L 证据)
3. **区域级**:进入/加码某市场(27 国覆盖+受众地理+经销商图三角验证)
4. **形式级**:该 KOL 用佣金还是一口价还是纯寄样(按历史同层级转化学)
5. **时机级**:发布时间窗(评论活跃时段已有)+ 大促日历对齐
6. **产品级**:SKU 主推轮换(需求信号 × 库存 × 竞品空缺)

每个动作:原因/证据链/**预测(入台账)**/成本/审批人/验收规则/驳回学习。

## 六、修订执行批次

- **批 0 解锁(1天)**:收敛 + Shopify webhook(你)+ 员工实测 —— 不变
- **批 1 度量真相层(3-5天)**:GMV桥/单位经济/KOL分层P&L —— 不变
- **批 1.5 信号接入 A 级(1周,可与批1并行)**:机身日历+Trends+Amazon排名+eBay残值+YT建议+竞品签约聚合 → 统一落 market_signal/observation
- **批 2 三个营销脑 + 需求-供给矩阵(1.5周)**:v1 的组合/创意/SOV + **卡口×焦段×价位的需求-供给-竞品三维矩阵**(369 SKU 知识库为骨架)
- **批 3 预测台账 + Action Inbox 2.0(1周)**:所有建议入台账;准确率仪表;经营级动作类型
- **批 4 规模基建(滴灌)**:token池/本地worker/移动审批/治理(any→500, placeholder→300 折进各批DoD)
- **批 5 多租户(第4周后)**:先自用出准确率数据再卖——**准确率仪表就是销售页**

## 七、和"平台的平台"的对照(回答差异化质疑)

| | CreatorIQ/Grin 类 | V-KPI v2 |
|---|---|---|
| 找人 | 库+过滤器 | 需求预测驱动圈人(机身脉冲→生态KOL) |
| ROI | 挂链接算转化 | 全链归因+组合P&L+预算再平衡 |
| 内容 | 表现报表 | 逐帧理解→反向生成brief |
| 智能 | 打分黑箱 | 预测台账+公开准确率+错例学习 |
| 品类 | 通用 | 镜头生态领域模型(卡口/焦段/机身耦合) |
| 数据壁垒 | 平台方的 | **自有闭环:SKU×KOL×内容特征×地区×订单** |

壁垒一句话:**全世界只有这套系统同时知道"哪支镜头、被哪种内容、在哪个国家、卖给了谁"——而且每天在变准。**

## 八、品牌脉搏日报(用户点名 2026-07-03)

**每天一份品牌热度+正负面舆情,自动生成、异动报警。**

数据源(全部已在库,零新增抓取起步):
- 评论情感:comment_sentiment 管线(已有)按日聚合,官号+已合作 KOL 内容下的评论
- Reddit 讨论:market_insights(已有)中品牌相关贴的量与情感
- B&H 用户评论:vkpi_bh_reviews(今日转正)按 SKU 聚合星级/关键词
- 品牌信号:vkpi_brand_signal + 竞品雷达(已有)
- 提及量:深析 viltrox_detected / 百家饭指数的日度变化

产出(每日 09:00 中国,挂现有调度):
1. **热度指数**:提及量 7 日移动均线 + 环比(按平台分解)
2. **情感面板**:正/负/中占比 + 环比;负面 TOP3 原文引用(带链接)+ 归因(产品质量/价格/物流/对焦固件…按关键词分类)
3. **异动报警**:负面占比单日跳升 >X% 或出现高粉账号负面 → 即时通知(复用哨兵告警通道)
4. 落 Dashboard「品牌脉搏」卡 + 写入 AI Today 供简报引用
5. **入预测台账**:负面异动后自动立"48h 内是否扩散"预测,对答案校准报警阈值

v0 今天可建(内部数据);v1 接入 A 级信号后补 Google News/Trends 维度。

## 九、焦段推动决策(用户点名 2026-07-03)

**回答:下一个该推哪个焦段×卡口,证据是什么。**

三维矩阵 = 需求 × 我方供给 × 竞品覆盖,按 卡口(E/Z/RF/X/L)× 焦段段位(超广/广/标/中长/长焦/微距/变焦)切格:

- **需求信号**:v0 用池内内容数据(该焦段内容的播放/互动密度)+ 评论提及 + B&H 评论量;v1 加 Trends 搜索量、Amazon 排名、eBay 残值、YT 搜索建议缺口
- **我方供给**:369 SKU 知识库(焦段/卡口/价位属性已有)→ 每格有无产品、价位带覆盖
- **竞品覆盖**:competitor_mentions 聚合(哪些焦段竞品声量大)+ B&H 竞品在售清单

输出(每周一自动刷新 + 随时可查):
1. 矩阵热力图:绿=需求高我有货竞品弱(**主推格**)、黄=需求高我有货竞品强(差异化打)、红=需求高我没货(产品线信号,给老板)、灰=需求低
2. 每个"主推格"生成战役建议:推荐 SKU + 圈出该生态 KOL TOP10 + 创意角度(接 brief 技能)
3. **入预测台账**:每个主推建议立"该 SKU 30 天内容量/互动 +Y%"预测

v0 一周内可建(内部+B&H);机身发布日历接入后升级为"事件触发式"(新机→矩阵重算→窗口战役)。
