## 第 1 刀:闭环点火

### 1A 修桥(先做,已坐实的真 bug)
**断点**:`gtm_bets.py` 生成的 bet 顶层无 `kol_pool_id` 键(只嵌在 `bet_key='kol:{id}'` :229、`subject={'entity_type':'kol','entity_id':kid}` :248);`verdict_flow.py:_bet_context` 的 `pick('kol_pool_id')`(:213-221)必 miss,兜底 :222 只认 `entity_type=='kol_pool'` 而实际落 `'kol'` → 也 miss → outcomes INSERT(:513)写 NULL → `gtm_windows.py:319` 走 no_kol 路径,7/14/28 三窗全饿死。

**修法(双保险)**:
1. `materialize.py` payload 顶层加 `kol_pool_id`(subject 为 kol 时);
2. `verdict_flow.py:222` 兜底放宽接受 `entity_type=='kol'`。

**单测**:bet → materialize → verdict → outcome → window 全链贯通,断言 `kol_pool_id` 非 NULL。
