# VIA / V-KPI 操作说明书 —— 找人 → 收藏 → 建项目加人

> 版本 v1 · 2026-06-30 · 适用站点 viltroxtest.com
> 面向:营销团队日常操作。覆盖三段主线:**KOL Pool 三种模式找人 → 收藏进 MY KOL → 创建项目并加 KOL**。

---

## 0. 一句话主线

```
KOL Pool「找达人」找到人  →  「加入收藏」进 MY KOL  →  Projects 建项目 → 「添加 KOL」拉人进项目跑合作
```

- **KOL Pool** = 找人 + 看视频深析的入口(三种模式)。
- **MY KOL** = 你个人挑出来要盯的人(收藏夹)。
- **Projects** = 真正开干的地方(寄样、内容、合同、复盘)。

三者关系:`Pool 是大池子 → 收藏到 MY KOL 是你的短名单 → 加进 Project 才进入合作流程`。**搜到 ≠ 归你**,要手动收藏才算你的;**收藏 ≠ 在跑**,要加进项目才开始合作。

---

## 1. KOL Pool · 「找达人」三种模式

进入左侧 **KOL Pool** → 中部「找达人」面板。右上角三个切换标签:**Video / Profile / 查找**。

输入框占位提示:
> `粘贴 KOL 主页 / 视频 URL,或输入产品需求,例如: 35mm 低光人像 YouTube 摄影师`

**面板会自动判断你贴的是什么**:贴链接 → 按钮变「查看」;输入文字需求 → 按钮变「查找」。

---

### 1.1 Video 模式 —— 贴一条视频,看内容深析

**用途**:已经盯上某条视频,想看它讲了啥、值不值、这个创作者合不合适。

**操作**:
1. 贴一条**单条视频链接**(Instagram Reel、TikTok、YouTube 均可)。
2. 点 **「查看」**。
3. 系统**自动**跑视频深析(无需再点第二个按钮)。

**你会看到(从上到下)**:
- **类型徽章**:`Video URL` + 平台(Instagram/TikTok/YouTube)+ `库内已有此人`/`库内暂无此人`。
- **创作者卡**:头像、handle、粉丝、简介(点「点开全部字段」展开;点卡片打开右侧详情抽屉)。
- **视频播放器**:可直接在卡里播(YouTube 内嵌、IG/TikTok 走缓存流);若是图文/多图轮播帖,显示成左右滑动的**图片轮播**。
- **分镜时间线**:`[00:00] 关键画面 / [00:09] …`(后台异步跑,**会原地丝滑补上,不用刷新**)。
- **评分两卡**:`内容质量`(0-100)+ `投放价值`(0-100),颜色绿>黄>红。
- **判定文案**:`最终判定` 一句话结论 + `内容概述`。
- **心动 / 风险 标签**:`心动: …`(紫)、`风险: …`(琥珀)。
- **三观 / 归因 / 建议**:展开看价值观、画面好看归谁、下一步怎么改。

**完成提示**:`视频分析完成,已入库 · 耗时 X:XX`,并出现 **「查看完整分析 →」**(打开详情抽屉)和 **「发现并分析全部视频」**。

> ⚠️ **TikTok 偶尔抓不到**:会提示 `TikTok 视频有时拿不到,可能需要重试`,点 **「重试分析」** 即可(TikTok 比 IG 慢一点,耐心等 1-3 分钟)。
> 💡 **分析口径**:这是「**找达人**」视角 —— 哪怕视频拍的是竞品,也按「这创作者值不值得接触合作」来判,**不会因为不是 Viltrox 产品就判彻底失败**;结论会分开说「这条对投放的价值」和「创作者对未来合作的契合度」。

---

### 1.2 Profile 模式 —— 贴主页,抓账号资料

**用途**:想快速建档一个账号,看粉丝/简介/代表作。

**操作**:
1. 贴 **账号主页链接**(IG 账号页、YouTube 频道、TikTok 用户页)。
2. 点 **「查看」**。
3. 系统**自动抓资料入库**,并顺带分析 **2 条代表视频**作为账号深析底料。

**你会看到**:
- **账号资料卡**:头像、handle、平台、粉丝数、帖数、简介(英文简介可点「译中文」)。缺的字段如实留空,不编造。
- **完成横幅**:`资料已入库 · 账号深度分析进行中(2 条代表视频,完成后「查看完整分析」即出 LLM 账号分)`。
- 两个按钮:
  - **「发现并分析全部视频」**:抓该 KOL 全部历史视频(最多 ~120 条)逐条排队深析,进度看左侧任务板。
  - **「查看完整分析 →」**:打开右侧详情抽屉看账号深析。

---

### 1.3 查找 模式 —— 描述产品需求,系统帮你找人

**用途**:手上有个产品/SKU,不知道找谁,让系统按人群去库内召回 + 全网发现。

**操作**:
1. 输入**自然语言需求**,例:`35mm 低光人像 YouTube 摄影师` / `相机三脚架 开箱 TikTok`。
2. 点 **「查找」**(或回车)。

**你会看到三个框**:

**① 要找什么样的人**(产品人群分析,**可编辑**)
- 系统先用 AI 拆出:产品定位、检索词、目标人群、**理想属性**标签、**规避属性**标签(带删除线)。
- 觉得不准 → 点 **「编辑」** 改写人群描述 → **「用此重搜」**。
- 若 AI 暂不可用,会提示已用基础检索匹配,结果照样能看。

**② 库内已有的人**(同步召回,从已入库 KOL 里匹配)
- 每张卡:头像、名字、粉丝、平台,加三类徽章:`契合·高/中/低`、`📈 N 曝光`、`👤 新人`、`✨ 新鲜`、`🔗 低合作`,以及「为何适合」一句话。
- 点卡片打开详情抽屉。

**③ 全网新发现的人**(异步,**恒开**,优先新人)
- **发现平台**:勾选 YouTube / Instagram / TikTok(可多选;改勾选即时过滤,无需重搜)。
- **区域**:下拉选目标市场(默认 `全球·英文`;选非英语区会按当地语言搜),并默认勾选 **`排除 中国/港/台 地区`**(海外中文博主放行)。
- 改了平台/区域 → 点 **「重新全网查找」**。
- **选人工具栏**(勾选发现项后出现):
  - **「加入我的 MY KOL」**:勾中的人进你的收藏(不自动进项目)。
  - **「批准并建草案」**:一键建项目草案(带预算/风险估算)。
  - **「生成话术」**:为选中的人生成合作邮件 + SOW 草案(仅供参考,人审后**手动外发**,不承诺价格)。

---

### 1.4 「最近历史 · N」

输入框下方的折叠条。点 **「展开」** 看最近的搜索/分析记录(类型徽章 + 内容 + 相对时间 + 状态点:🟢已完成 / 🟡部分 / 🟠未完成 / 🔵排队)。**点任一条可恢复那次搜索的结果**(没跑完的会继续后台补);换标签页/刷新不丢。

## 2. 收藏进 MY KOL

### 2.1 怎么收藏(两处入口)

| 位置 | 按钮 |
|---|---|
| KOL 列表行 | 名字旁的 **⭐ 星标**(已收藏=金色填充) |
| KOL **详情抽屉**底部 | **「加入收藏」**(已收藏显示 **「已收藏」**,金色底) |

收藏一个**新发现候选**时,系统会自动先建真记录再收藏(你无感)。

### 2.2 「收藏」≠「入主表」

| | 加入收藏(favorite) | 入主表(promote) |
|---|---|---|
| 含义 | 你的个人观察夹 / 短名单 | 把候选**正式写进主库** |
| 按钮 | `加入收藏` / `已收藏` | `入主表` / `已入主表 ✓` |
| 适用 | 任何人(库存/新发现) | 只针对**新发现候选** |
| 归宿 | MY KOL 的「关注列表」 | 主库,转正为长期合作/项目 KOL |

> `入主表` 是一次性动作,成功后变 `已入主表 ✓`,**不可撤销**。

### 2.3 MY KOL 页能干嘛

左侧 **MY KOL**:看你收藏的所有人。每人显示头像/handle/粉丝/Fit 分,以及来源标签(`收藏`/`长期合作`/`项目`)和关联项目数。可按平台筛选、搜索。点人打开右侧面板看其代表视频 + Viltrox 证据 + 视频分析。

### 2.4 「添加联系方式 / 发起合作邀请」

详情抽屉里:有邮箱时按钮是 **「发起合作邀请」**,无邮箱时是 **「添加联系方式」**。点开弹窗:
- **邮件邀请** tab:选产品 → 编辑主题/正文 → **「AI 优化」**润色 → **「复制文案」**。⚠️ **系统不代发邮件**,你复制后自己去邮箱发(合规+安全)。
- **添加额外渠道** tab:填邮箱 / 选渠道(IG DM、TikTok DM、YT About、Discord、X DM、WeChat)填 handle → **「保存联系方式」**。

## 3. 创建项目 + 添加 KOL

### 3.1 创建一个推广(项目)

1. 进左侧 **Projects** → 点 **「创建推广」**。
2. 弹窗标题 **「新建推广」**,填:
   - **推广名称**(必填,例:`AF 35mm F1.2 LAB FE 上市推广`)。
   - **主推产品**(可自动完成,命中真 SKU 会自动带出**价格**)。
   - 可选:状态(规划中/进行中/收尾中/已结束)、目标 KOL 数、预算 USD、已花 USD、开始/结束时间、负责人、推广类型。
3. 点 **「创建推广」**。提示:`推广项目已创建。后续阶段推进、费用、物流和证据请在项目详情里处理。`

> 新项目默认阶段固定为 **discovery(发现)**;后续在项目详情里推进。创建时填的「状态」只作备注。

### 3.2 把 KOL 加进项目(主入口)

1. 打开项目详情 → 点上方 **「添加 KOL」**(或 Tab **「新增 KOL」**)。
2. 弹窗标题 **「从 MY KOL Pool 添加」**,副标题告诉你选中后进入该项目的「发现」阶段。
3. **来源切换**:默认 **「我的收藏」**;需要更大范围点 **「从全池查找 →」**(从全池选中的人会自动加入你的收藏),再点 **「← 回到我的收藏」** 返回。
4. 用搜索框 / 平台筛选 / 跟进状态(全部·可添加·已被跟进)缩小范围(列表最多显示前 80 条)。
5. 勾选要加的人:
   - `可添加`(青绿)=可勾;
   - `已被 XX 跟进`(琥珀,灰态)=已被别人认领,普通用户勾不动。
6. 点 **「添加 N 个 KOL」**。提示:`已向「项目名」写入 N 个 KOL,跳过 M 个已有项。`

> 也可从单个 KOL 的详情抽屉用 **「加入项目」** 加(单个,非批量,次要入口)。

### 3.3 KOL 进项目后能管理什么

项目详情有 4 个 Tab:

| Tab | 干啥 |
|---|---|
| **参与 KOL** | 已加入的人 + 阶段 + 发布数 + 曝光;行内 **「→」** 推进阶段 |
| **待发布内容** | 待发布内容草稿队列 |
| **物料** | 寄样/产品物料库存与状态 |
| **新增 KOL** | 按 handle 查找邀请新 KOL |

项目层面板还有:KOL 进度漏斗(discovery→published→measured)、瓶颈告警、4 大 KPI 卡(参与数/发布率/曝光/短链点击)、费用账本、合同管理(模板生成 + OCR 提取 + 签署版)。

### 3.4 阶段流转(主流程)

```
discovery 发现 → contacted 已联系 → replied 已回复 → agreed 合作同意
→ shipped 已发货 → received 已签收 → published 已发布 → measured 已复盘 → closed 关闭
```

> - 推进到 **shipped** 必须填快递单号。
> - 终态(closed / released / lost / cancelled)进入后不能回退。
> - 加进项目的每个 KOL 的「负责人」由系统按其认领自动分配,**不等于项目负责人**。

## 4. 常见问题 / 注意事项

- **搜到的人没进 MY KOL?** —— 搜索结果只是池子展示,**必须点「加入收藏」**才进 MY KOL。
- **视频/分镜没立刻出来?** —— 后台异步跑,**会原地补上**;TikTok 偶尔要点「重试分析」。
- **同一个人重复出现 / 视频挂错人?** —— 可能是**归属串了**(达人的测评视频被挂到品牌池)。反馈给管理员按 content_url 归位即可(改归属不影响评分)。
- **邮件能自动发吗?** —— 不能,系统只生成/润色文案,你**复制后手动发**。
- **KOL 加不进项目(灰态)?** —— 被别人认领跟进了,需管理员强制(force)才能覆盖。
- **预算护栏** —— 生成话术/AI 优化等会走 LLM 预算闸,超额时降级为模板或提示上限。
