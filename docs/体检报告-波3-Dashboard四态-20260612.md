## 三、红单(8 条,按疼痛排序)

### R1 · 收藏数/漏斗卡缺位——769+ 真数据落库,Dashboard 一张卡都没亮(最疼)
- **实证**:DB `SELECT COUNT(*), COUNT(DISTINCT kol_pool_id) FROM vkpi_kol_pool_favorites` = **772 | 715**(C5 backfill 769 对后自然增长);在役 assignments(非 churned/cancelled)=2022。
- 但 HTTP 实测 `GET /api/admin/vkpi/dashboard?window_days=30` 响应:`funnel ∉ evidence_metrics`,全文无 "favorit" 字样——**C9(后端漏斗聚合块)未施工**:`backend/app/domains/dashboard/summary.py`(533 行)grep funnel/favorites 零命中。
- 前端同样无消费:`normalizers.ts` 无 funnel 块解析,首页无收藏卡/在役卡/已发布卡/转化条——**C10 未施工**(`docs/KOL-funnel-survey-20260611.md` 施工卡 C9/C10 在册)。
- 痛点:四环漏斗(Pool 1128 → 收藏 715 → 在役 → 已发布)是本轮 C1-C5 全部投入的回报出口,目前管理层在 Dashboard 上看不到任何一格。

### R2 · Total Exposure / Engagement 双 KPI 卡被一条 Rick Astley 垃圾证据行污染
- **实证**:`vkpi_kol_video_evidence` id=1603,kol_pool_id=1525(photographyblog-Mark Goldstein【MEDIA】),title "Rick Astley - Never Gonna Give You Up",url `dQw4w9WgXcQ`,view_count=1,777,763,236,like_count=19,128,459,**is_active=t**。
- 全库 active 证据 SUM(view_count)=1,804,858,030 → 该行占 **98.5%**;互动 21,568,141/23,272,505 = **92.7%**。
- 卡面后果:Total Exposure 显示 1.80B(几乎全是 rickroll);Engagement Rate 显示 1.29%(剔除后 ≈6.29%,失真 5 倍);KPI 钻取 `movers_tabs.by_views` 第一名也是这条(HTTP 实测可见)。
- 性质:接真 API + 真落库 ≠ 真业务值,这是「真值外衣下的停摆」,两张核心 KPI 卡同时失真。

### R3 · Content Calendar「7 天推广日历」停摆 15 天
- **实证**:DB `MAX(posted_at) FROM vkpi_channel_post_metrics` = **2026-05-28**(今天 06-12);HTTP `dashboard/recent-content` 30 条全部 ≤5/28。
- 卡面后果:日历桶实显 5/26-5/28,却以「7 天日历」名义呈现(`normalizers.ts:527-543`)。
- 附带 bug:recent-content 同批存在 `"2026-05-28"` 与 `"Thu May 28"` 两种日期串,`slice(0,10)` 分桶会把同一天拆成两桶(`normalizers.ts:531`)。

### R4 · AI Today 卡假置信度 + brief 停更 20 天
- **实证**:`normalizers.ts:553` `confidence: brief.is_real ? 72 : 0` —— **72% 是前端硬编码**,与任何模型/数据无关;卡面渲染 `${insight.confidence}% conf`(`AIIntelligenceCard.tsx:31`)。
