## 二、断点清单(如实)
1. **无员工互发私信**——vkpi_messages 是"对象留档"不是"人对人";员工间沟通仍在系统外。
2. **消息无已读回执/无@提醒**——留档后对方不被通知(TeamModal「@提及」为待接入占位)。
3. **沟通无统一时间线视图**——散落在项目详情/审计日志;N1 CRM 时间线(spec 已档)即为此而设。
4. **通知不可达员工动作**——通知详情「跳转到关联」待接入(本批已诚实置灰)。
5. 留档不可编辑/撤回(只追加)——审计友好但误录无法修正,需 N1 的编辑抽屉。

## 三、员工日常三场景操作指引
1. **联系 KOL 并留档**:项目详情 → 时间线「联系 KOL」→(可选)AI 草稿 → 复制到平台发送 → 「记录沟通」留档。
2. **看自己任务进度**:左侧泳道三道+排队位次(「前方 N 个」);点账号分析任务回 MY KOL 行,项目任务回项目详情。
3. **给项目留言/存证**:时间线「上传证据」(截图)或项目消息;合同走「上传合同」就地归档自动推进。

## 四、改进建议(按价值排序)
1. **N1 CRM 时间线复活**(spec 在档):统一沟通视图+编辑抽屉+附件——解决断点 1/3/5。
2. 留档触发对方站内通知(已有通知设施,缺接线)。
3. 已读回执(messages 表加 read_at,轻)。
4. @提及接通(TeamModal 占位已在)。
