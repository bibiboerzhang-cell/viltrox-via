## 一、体检判决:合理省钱 vs 会咬人

### 1a. 被外部对标确认「合理省钱」的简化(不动)
| 我们的做法 | 外部验证 |
|---|---|
| Gemini 1fps 帧采样+上下文缓存+Batch | 多模态 LLM 低帧采样=2026 主流本尊;24fps=21.5 倍成本,永远别为「精度」调帧率 |
| 自研 Postgres SKIP LOCKED lease | PgQueuer/Procrastinate/Hatchet 全押同一模式;Temporal 仅当工作流种类爆炸再评估 |
| 贪心 set-cover 组合 | 学术标准同款(子模最大化,保证 63% 最优);唯一升级=按边际增益/报价排序(cost-aware) |
| 分位数预测 | 路线成立;缺的是校准与收缩(见欠账1) |
| 十一维余弦找相似 | two-tower 的手工退化版,方向不落后;语料>5k 再上 embedding 索引 |
| 词表规则分类(招牌/焦段/FTC) | 带 method 标签+置信度=可控简化;召回层是短板(见 1c) |
| 自建整体 | GitHub 无成熟 influencer 平台开源轮子;CreatorIQ $25-60K/年、GRIN $12-30K/年,自用规模买=倒贴 |

### 1b. 会咬人的欠账(五刀修复单,按 ROI 排序)
1. **刀1·预测对答案闭环(ROI 最高)**:performance_forecast 在线算不落库→建 `vkpi_forecast_log` 每次调用落一行,每日 job 回填 30 天后 actual 播放;refresh_open_outcomes 挂稳每日。效果:已建成的 L 轨道四件(台账/记分卡/影子评测/复盘)立即从 pending 转正,系数获得首个校准源。
2. **刀2·解析债回填(零成本白捡)**:Apify raw 里邮箱/评论者ID/语言/媒体种类字段俱在而列全空→一次性回填脚本+langdetect。效果:受众样本荒/geo 代理口径/评论覆盖三债同抬,不花一分外采钱。
3. **刀3·报价台账灌种**:历史合同价回填 vkpi_kol_rates(source=contract)+ roster 预算段「全员 CPM 兜底时降级 estimate_only」护栏——消除拍脑袋常数被汇总成预算总价误导决策的最大单点风险。
4. **刀4·算法件补测+helper 收敛**:8 个纯函数算法件 golden-fixture 单测;_truthy/_loads 等 20-58 份副本收敛进 _compat.py(AST 差分证等价);verify.sh 加「>1000 行即 fail」。
5. **刀5·工程税**:main.py 79 路由改 registry 循环;前端路由级分包砍 1.1MB 主 chunk;部署脚本强制先过 verify.sh(绿 CI 变真发布门)。

### 1c. 算法级具体缺陷(内审实锤,修复一句话)
- signature_profile:英文词表无词边界(加 \b 正则);focal_matrix:「35mm 胶片」语境误判焦段(加 film/equivalent 负语境);video_similarity:余弦量纲测的是「质量相似」非「内容相似」(每维减语料均值);brand_pulse:to_jsonb 全表拉回杀索引(publish_date 转正列+索引);forecast:无时间衰减;roster:UNKNOWN 桶互相折减假耦合(改每 KOL 独立桶);quality:LLM 分当真值有漂移风险(记录 model/prompt 版本+季度人工抽检 20 条)。
- **召回层是全链真短板**:词表=词面匹配,漏语义相近用词不同的创作者。升级=三段式:便宜 embedding 召回(bge-m3/Gemini embedding)→十一维粗排→LLM 只重排 top-20 并输出「为何合适」(正好落实搜索引擎硬规格,单次增量成本几美分)。

## 二、对标缺口:商业平台有、我们没有(按值得抄的程度)

1. **客户库挖 KOL(Upfluence 独有,最值得抄的单点)**:用 Shopify 订单客户(邮箱/姓名)撞 KOL Pool+社媒——Viltrox 买家里必有摄影博主,零外联成本、天然高契合,一刀可做。
2. **品牌安全扫描(CreatorIQ SafeIQ/Later 12 类风险)**:签约/送样前 Agent 跑一次公开源(新闻/论坛)风险扫描,防口碑翻车;LLM+搜索低成本可做。
3. **受众真实性分(HypeAuditor AQS,95.5% 欺诈检出)**:用已有评论管线做 bot 信号(突涨粉/机器评论/互赞组模式),防给假量 KOL 送样。
4. **UGC 授权+付费放大(Aspire CreatorAds/Meta Partnership Ads)**:履约闭环加「使用权限确认」字段,KOL 内容可合法投广告;先手动流程。
5. **折扣码批量双通道(Mavely $2.5 亿收购验证的方向)**:每 KOL 专属折扣码批量生成+短链/码双通道合并去重,归因下钻到镜头 SKU 级——我们 viltroxvia.com 架构就差这一步到商业平台同级。
6. **GIA 人机边界(GRIN,与我们驾照制度同构)**:三审批点(送样前/付费前/内容审核)+agent 每日摘要播报;可注册免费版偷师交互。
7. **辅助归因视角**:发帖后 N 天品牌搜索/直访抬升,别只信短链 last-click;adstock 衰减权重(7/14/30 天)抄 MMM 概念不接整库。

**警示信号**:Aspire 转 Meta 一方 API、Shopify Collabs 停新创作者注册——爬虫路线长期脆弱+第三方生态会收缩,关键官号数据尽量走官方 API,自建外联+归因路线被反向验证。

## 三、社区未执行创意(Reddit/HN 挖矿,全部低成本可做)

**行业怨气=我们的机会**(器材垂类特有):两周借测逼还、黑名单文化、「exposure」当报酬、87% 创作者被拖款、纯送测只有 6% 愿接。

1. **外联三承诺(零代码)**:「7 天内付款 + 送测留用不回收 + 书面承诺不干预差评」写进外联模板——专收被大厂伤过的测评人;契合评分加「敢给差评」信号(历史上给过差评=可信度加分)。
2. **gifted→posted 履约漏斗**:送测不发帖是行业第一黑洞;加状态列+到期自动催更+送测叠佣金码(纯送测→混合模式)。
3. **战绩卡回传(成本≈一个模板,留人效果最好)**:给合作 KOL 定期发「你带来 X 点击 Y 单」摘要——创作者调研里最想要却几乎没品牌给的东西;受众 geo 数据也是买不到的回馈。
4. **评论区营销 Top5 清单**:反向用评论管线,每日扫摄影垂类热门视频→推「官号值得去评论的 Top5 机会」(Vita Coco 单条评论换 2.5 亿曝光的打法,我们数据现成)。
5. **长尾创作者军团**:发射台加「长尾波次」模板(50-100 个 nano/micro 小额送测+佣金码一键铺量;TikTok Shop 开放联盟已验证长尾合计 $50-100K/月量级)。
6. **爆款授权池(双向)**:①发现引擎扫到的「自然提及 Viltrox 的既有爆款」标记出来谈小额授权复用(比约稿便宜快);②自建授权台账(范围+到期+提醒)防自己超期用素材。
7. **真个性化外联**:外联信自动引用对方具体视频里的具体片段/观点(深析已产出)——重复跟进+个性化是工具层公认空白,我们有独家弹药,回复率可 A/B 验证。

## 四、Viltrox 自己怎么做 Marketing(不只找 KOL,含自己推)

同行标杆:SmallRig(共创 DreamRig+审核制 2.7 万人 FB 群+Awards 一届 3891 部投稿)、Ulanzi(场景痛点短视频 88 万粉 TT)、Godox(借力第三方社群)、Sigma/Tamron(荣誉型大使+EDU 学生返现)。

### 零成本(本周就能动)
1. **固件更新当营销事件**:每次固件走发射台流程——changelog 写成故事、主动推给曾给差评的评测人邀请复测造第二波报道(135 LAB 已自证此路)。
2. **T-30→T+30 发布 SOP 编进发射台**:T-30 rumor 站投料 → T-14 批量 embargo 寄样 → T0 多评测人同日解禁 → T+7 差评聚类→固件工单→复测邀约,全链 V-KPI 内闭环。
3. **免费 LUT/样片页改「邮箱换下载」**:每个履约 KOL 视频描述区带 LUT 归因短链——下载即线索,进邮件序列,接进现有归因链。
4. **KOL 短链一律导独立站**(viltrox.com)非亚马逊,否则归因链断;亚马逊管搜索流量与大促,独立站管会员/共创/归因。

### 低成本
5. **审核制 Facebook「Viltrox Shooters」群**(此品类别做 Discord):或更省——收编现有第三方 Viltrox 用户群群主,给新品内测+固件直通特权(Godox 借力模式);群内讨论喂新品选题=市场之声的活水源。
6. **联盟计划对齐行业标准件**:10% 佣金+30 天 cookie(SmallRig/Ulanzi 同款)+「寄样资格」做层级晋升奖励,层级升降直接吃 V-KPI 预测战绩分;对中高端摄影师用「Viltrox 认证讲师/大使」荣誉头衔+教育折扣码(Tamron EDU 模式,天然可归因)。

### 低到中成本
7. **年度样片/短片赛**(缩小版 SmallRig Awards):报名条款内置二创授权,投稿人自动进 KOL Pool 建档——**比赛即发现引擎**。
8. **轻量共创**(抄 DreamRig 的壳):头部履约 KOL 参与下一支镜头焦段投票/命名/限定配色,挂名+分成,条款进履约模块。
9. **竞品预警标签**:7Artisans/TTArtisan 与我们共用同一批中小评测人——给「行业共用评测人」打标签,追踪其测竞品时间差,被抢先=预警信号。
10. **线下漏斗进系统**:展会体验数据(试用次数/多镜头试用率)进 V-KPI;校园工作坊让海外大使代执行(成本=样品+讲课费)。
