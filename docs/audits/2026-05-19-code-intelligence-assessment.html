5. 当前代码被复刻的可能性与护城河

代码可复刻度：72%FastAPI + React + 规则推荐 + LLM Gateway，外部团队可以按功能复刻。
数据可复刻度：18%1012 历史 KOL、合作关系、内部 ROI、员工反馈难复制。
流程可复刻度：35%如果 V-KPI 深度绑定 130 人任务、归因和复盘，流程会变成护城河。

别人容易复制什么

页面外观、KOL 搜索、基础评分、自然语言搜索、竞品监控、LLM 总结，这些都不是护城河。只要有预算和工程师，2-6 个月能做出“像”的系统。

别人难复制什么

Viltrox 自有的历史合作、产品家族映射、KOL 关系、Shopify/Amazon 归因、员工处理反馈、真实任务结果、竞品响应记录、内容团队采纳记录。这些数据越多，系统越难被复制。

反复刻策略

  • 把推荐理由、反馈、归因、证据全部写入私有 Decision Log。
  • 把 KOL/Product/Campaign/Content/Competitor/Staff/Outcome 做成 Entity Edge Graph。
  • 评分规则可配置但不暴露；核心权重、playbooks、feedback features 放服务端。
  • 前端可以漂亮，但不要把业务推理完整写死在前端。
  • 真正的护城河不是代码混淆，而是运营闭环和内部数据飞轮。
