## 一、本地算力下放

### 1a. 已有底座(不必从零)
| 能力 | 落点 |
|---|---|
| 视频下载/抽帧/关键帧/预检/失败分类 | services/media/{video_download,frames,video_keyframes}.py、services/scraping/ytdlp*.py |
| 本地库存下载脚本 | scripts/download_kol_inventory.py、prepare_kol_local_inventory.py |
| worker 心跳/任务队列/失败分类 | workers/apify_jobs_worker.py、services/jobs/queue.py、domains/tasks/queue_view.py |
| 模型路由雏形 | platform/models/{registry,router}.py + adapters(qwen/openai stub) |
| Embedding/召回 | scripts/build_kol_profile_index.py、expand_kol_profile_index.py |
| 前期验证(7-04 四路) | key 经 LiteLLM 虚拟 key 不落盘;轮转仅 Gemini 多 project 真扩容;单 key 撑 6-18 视频线路;桌面端选型 Tauri(远期);九缺口施工单在技术全景报告第九章 |

### 1b. 半成未收口(4 项)
1. worker 概念有但全在服务端:缺 用户电脑注册/能力上报/本地拉活/结果上传/失败恢复/本地 UI
2. 本地模型只有 adapter+registry 层:推荐/评论分析/联系方式提取/市场判断均未走本地模型,本机无 ollama/llama-server
3. 视频库存是工程脚本非团队工作流:缺 页面入口/任务状态/进度/路径管理/云同步/R2-本地-DB 三方一致性
4. 任务看板看不见本地节点:缺 哪台机在跑/CPU-GPU-内存/空闲态/失败原因/本地 vs 云派活策略

### 1c. 净缺口(6 项 = Local Worker 产品化)
1. **Local Worker App**(核心):登录/绑定设备/接任务/跑下载抽帧embedding/上传/状态
2. **设备注册表** `vkpi_worker_devices`(device_id/staff_id/device_name/platform/capabilities/last_seen_at/status/trust_level)
3. **任务派发策略**:适合本地否/哪台空闲/数据权限/失败回收云端
4. **短期任务 token**:云端签发、单任务、过期失效、结果上传带签名——本地永不落长期 key(红线)
5. **本地结果校验**:hash/帧数/时长/metadata 结构/URL 匹配——本地上传不可直信
6. **本地模型运行时**:Ollama 或 MLX + 模型下载/能力登记/local inference endpoint/与云端 LLM 一致性评估

### 1d. 架构定案(裁决记录)
**下放本地**:下载/转码/抽帧/压缩(yt-dlp+ffmpeg 最吃带宽磁盘)、文本清洗/邮箱链接提取/语言识别/国家词表、embedding/向量召回/rerank/去重/相似初筛、截图缩略图/OCR/小模型摘要、失败预检(404/会员/年龄限制)、本地缓存。
**留在云端(不下放红线)**:权限判断/组织隔离/审计、最终写库、V6 Fit 等重要分数写入、履约状态/发货/订单/短链归因、多人共享队列调度、高价值最终 LLM 判断、一切公司统一口径结论。

```
用户电脑 Local Worker(下载/抽帧/清洗/embedding/预筛/缓存)
        ↓ 短期token+签名结果
云端 API(派发/权限/审计/落库/成本控制)
        ↓
云端 LLM/统一模型路由(最终分析/报告/决策)
```

**落地路线**:先 Mac 命令行/菜单栏 Worker MVP(M4 Max=第一节点),只接 4 类安全任务(video_precheck/download_frames/comment_clean+metadata_extract/embedding_build);本地只上传 JSON 结果+文件+hash+耗时+错误码,云端校验后落库;看板显示是哪台机器跑的。稳定后扩 Windows,最后才考虑桌面 App。手机/iPad 只做审批查看不做重计算。
**风险**:员工环境差异(ffmpeg/yt-dlp 安装)、断网休眠中断恢复、客户端结果不可信必须校验、key 只走短期 token、不许员工机跑全量任务。
**收益**:云端下载/抽帧成本与队列拥堵明显下降;搜索因本地缓存更快;LLM 成本不明显降(除非本地模型预筛)。
