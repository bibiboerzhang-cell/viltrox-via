**已知限制(进门)**

- 激活链接 **48 小时**内有效且一次性;过期或打不开 → 找管理员重新生成。激活页只显示「链接是否有效」,不会回显你的邮箱和姓名,属正常。

- 不要在地址栏直接输入 `<BETA_URL>/login` 再刷新(目前会显示 404);请从 `<BETA_URL>` 根地址进入,站内跳转是正常的。

- 登录凭证只存在浏览器的安全 cookie 里;如果你用隐身窗口或禁用了 cookie,会一直停在登录页。

## 2. 核心闭环 8 步

登录(§1)之后,一条完整的路径是:**建/选产品 → 搜 KOL → 看详情 → 收藏 → MY KOL → 项目 → 履约 → 复盘**。
建议第一天至少走完前 5 步(约 15 分钟),后 3 步可以用演练数据。

### 第 1 步 建/选产品

在左侧「**KOL Pool**」的智能搜寻输入框里,用一句话写清**产品 + 需求**(型号、卡口、光圈、目标市场、平台),例如:
「美国 YouTube 人像摄影师,适合推 Viltrox 35mm f/1.2 X 卡口」;也可先在「**SKU 360**」里浏览现有产品目录再回来搜。

`[截图占位 2.1 搜索输入框 + SKU 360 目录]`

已知限制:
- 暂不支持在界面里**自建产品档案 / SKU**;目录里没有的新品,直接写在需求句子里。
- 需求句里的**光圈参数(如 f/1.2)目前可能未被识别**,请同时写型号与卡口,别只写光圈。

### 第 2 步 搜 KOL

点「搜索」:本地库的结果几秒内出现;随后系统会**自动在线补全**(通常 2–15 分钟),顶部进度条会显示进行到哪一步。

`[截图占位 2.2 结果墙 + 进度条]`

已知限制:
- 可能出现「**本次没有找到任何人选**」。原因之一:**已被同事收藏的人默认不出现在你的结果里**。请换平台 / 放宽条件重试,并把你输入的原话通过反馈发给我们。(系统已能在人选不够时按「同事已关注 → 题材放宽 → 证据放宽 → 资质待核验」四档补充候选并说明「为什么这么少」,但**界面展示还在接入**,当前你可能仍只看到空结果。)
- 在线补全最长约 **30 分钟**后会自动收敛为「部分完成」并保留已出的结果;过程中**不影响**已经出现的本地结果,可以继续操作,也可以随时取消补全。
- 目标市场的匹配还在校准:候选的「国家」只在平台自报时才填,没有的会留空;同市场的人排前面,标了「未核实」或「市场不符」的排后面。多个候选分数接近时,请以卡片上的「为何推荐」说明为准。
- 每人每天有在线发现**次数**额度(见 §3);超额会看到「今日『智能搜索·在线发现』额度已用完(N/N 次),将于 … UTC 重置;如需提额请联系管理员」,本地库搜索不受影响,**次日恢复**。同一账号 60 秒内连续发起超过 12 次在线搜索 / 深度分析类高成本操作会看到「操作太频繁」,稍等再试即可。
- 顶部会有「相关性仍在校准」一类提示——请多点「有用 / 没用」。目前反馈**只被记录,暂不会立刻改变排序**。

### 第 3 步 看详情

点候选卡片打开**详情抽屉**:「概览」(这人是谁 / 为何推荐)、「深度分析」、「受众」、「合作」四个分区;在「深度分析」里可以对一条视频发起分析(约 30 秒–1 分钟出结果)。

`[截图占位 2.3 详情抽屉四分区]`

已知限制:
- **联系方式(邮箱 / 电话)对测试账号默认隐藏**,显示为脱敏(如 `a***@gmail.com`)或「无权限」——这是有意为之,不是故障。
- 新候选的「合作历史 / 风险 / 产品线」多为空,属正常。
- 视频深度分析计入你的每日次数额度(见 §3,默认每天 20 条;每条成本约 $0.04,由公司承担)。
- 浅色主题下抽屉部分区域仍是深色底,不是故障。
- 偶尔会看到英文报错(如 "No permission for …")——意思是「无权限」,截图发给我们即可,不用反复重试。

### 第 4 步 收藏

在卡片或详情里点「收藏」(星标);再点一次即取消。

`[截图占位 2.4 收藏按钮 + 已收藏态]`

已知限制:
- 你收藏后,这个人**默认不再出现在同事的搜索结果里**(团队共享收藏机制)。测试期内请只收藏你真正想跟进的人;误收藏请及时取消。

### 第 5 步 MY KOL

左侧「**MY KOL**」→ 打开「我的收藏」快捷筛选 → 确认刚收藏的人在列表里 → 点行进详情。

`[截图占位 2.5 MY KOL 我的收藏]`

已知限制:
- 从 MY KOL **行内暂时没有「外联 / 发邮件」入口**;请从详情抽屉的「合作」分区操作。
- 「合作漏斗」「合作推进中」等卡片在你建项目前为空,属正常。

### 第 6 步 项目

回到搜索结果,勾选候选 → 点「**批准并建项目草案**」;或者到「**项目**」板块手动新建项目,再把收藏的人挂上去。

`[截图占位 2.6 建项目草案 / 项目卡片墙]`

已知限制:
- 「批准建草案」按钮要等在线补全到**终态**(完成 / 部分完成 / 已取消)才可点(否则是灰的,悬停会提示原因);最长 30 分钟自动到终态,等不及可先取消在线补全再试,或直接手动新建项目。
- 草案自带预算 / 风险估算,数字仅供参考。

### 第 7 步 履约

在「项目」板块看「**履约待办**」「履约阶段漏斗」「内容匹配」;KOL 发布内容后,在内容行点「✓ 复核」;系统没自动抓到的内容,可以手动录入内容链接。

`[截图占位 2.7 履约待办 + 内容匹配]`

已知限制:
- 测试环境里**订单归因、经销商等数据为空**,相关卡片显示「待接入 / 暂无」是正常的;带「[演示]」前缀的活动 / 审批 / 周报是团队放的示例,可以随意点,但不要当真实数据引用。
- 履约推进依赖真实发布内容;测试期可以用你或团队的公开视频链接做演练。

### 第 8 步 复盘

内容复核后点「**推进复盘**」;复盘结果会汇总到项目详情的「观察窗口」/「合作项目结果」。

`[截图占位 2.8 推进复盘 + 观察窗口]`

已知限制:
- 复盘要等观察窗口走完(**按天计**),测试期内可能只看到「等待中」。不必死等,把过程中不顺的地方反馈给我们更重要。

## 3. 费用说明

**哪些动作真的花钱**(其余——本地库搜索、收藏、建项目、履约录入——不花钱)。金额为团队估算,以实际账单为准:

| 动作 | 大约费用(估算) | 备注 |
|---|---|---|
| 在线发现一轮(Instagram) | ≈ $0.6 | 搜索时自动触发 |
| 在线发现一轮(TikTok) | ≈ $0.03 | |
| 在线发现一轮(YouTube) | $0 | |
| AI 规划(每次搜索) | ≈ $0.002 | |
| 视频深度分析(每条) | ≈ $0.04 | 详情抽屉里手动触发 |

**每人每日额度(公测期)**。按人、按 UTC 日计数;只有成功的操作才计数,报错不扣额度。数值是系统默认值,团队可按公测预算调整,调整后以界面提示为准:

| 项目 | 配置键名 | 默认值 |
|---|---|---|
| 在线发现搜索(每天几轮) | `VKPI_USER_DAILY_QUOTA_SMART_SEARCH_ONLINE` | 30 次 |
| 视频深度分析(每天几条) | `VKPI_USER_DAILY_QUOTA_VIDEO_DEEP_ANALYSIS` | 20 次 |
| 账号深抓(每天几个) | `VKPI_USER_DAILY_QUOTA_DEEP_CRAWL` | 40 次 |
| 外联生成 / 发送(每天几次) | `VKPI_USER_DAILY_QUOTA_OUTREACH_SEND` | 60 次 |
| 高成本操作连点上限 | `VKPI_USER_RATE_LIMIT_EXPENSIVE` | 60 秒内 12 次 |
| 额度总开关 | `VKPI_USER_QUOTA_ENABLED` | 开 |
| 额度重置时间 | (固定) | 每日 UTC 00:00 = 北京 08:00 = 美东 20:00(夏令时)/ 19:00(冬令时) |

超额时你会看到 429 提示「今日『…』额度已用完(N/N 次),将于 <日期 时刻> UTC 重置;如需提额请联系管理员」——不会有硬报错,**次日自动恢复**;需要临时加额度找 `<CONTACT>`。
另有公司级总预算:若看到「本轮预算已到上限」「候选预算已用尽」「数据源未就绪(配置 / 预算)」「AI 规划暂不可用,已用基础检索匹配」,是公司总闸或临时降级,本地检索仍可用。
