# V-KPI 使用说明书

> 给运营同学的上手指南。四件事:**找红人 → 收红人 → 做项目 → 办活动**。
> 看到的数据默认是「你自己的」——你负责的红人、你参与的项目和活动。需要更多权限找管理员在「系统设置 · 账号授权」里给你开。

---

## 一、找红人(KOL Pool · 找达人)

进入左侧 **KOL Pool**,顶部「找达人」一个入口,三种找法(切换 Tab):

| 方式 | 什么时候用 | 怎么填 |
|---|---|---|
| **视频 URL** | 你已经看到一条好视频,想认识作者 | 贴视频链接(YouTube / TikTok / Instagram),回车 |
| **账号 URL** | 你已经知道某个红人,想入库分析 | 贴主页链接(`youtube.com/@xxx`、`tiktok.com/@xxx`、`instagram.com/xxx`) |
| **产品需求** | 你只知道要推什么、不知道找谁 | 用一句话描述,例如「找适合 23mm 定焦的街拍摄影师」「适合 LED 补光灯的静物创作者」 |

**找完会发生什么:**
1. **即时结果** —— 几秒内先给一批「库里已有」的候选,带平台、粉丝、契合度。
2. **后台深找** —— 系统继续在全网找新人,完成后结果区自动刷新,左侧任务卡会提示「可打开」。
3. **最近历史** —— 入口下方「最近历史」记着你搜过什么(可读标签,如「IG @coco」「找人 · 街拍 23mm」),**只显示你自己的**,点开可回看;太长可「收起」。

**看结果:**
- 每个红人卡片有 **契合度**(高/中/相关)和「**为何适合**」一句话理由。
- **新人优先**:粉丝过载的大号会自动降权,帮你发现还没被抢的潜力新人。
- 点卡片展开 → 看视频分析、代表作、账号资料。视频能直接播(YouTube 嵌入 / IG·TikTok 走缓存或跳原帖)。

> 小贴士:搜不到/失败会**明确告诉你原因**(如「该平台暂不支持」「资料抓取失败」),不是没反应。

## 二、收红人(建档 + 收藏 + 认领)

找到合适的人,三步把他变成「你的资产」:

1. **建档**:在结果卡或详情里点建档/分析,系统抓基础资料 + 代表视频 + 做内容分析,完成后详情自动打开。
2. **收藏**:点收藏(♡),进你的 **MY KOL · 收藏/待跟进**。
3. **认领**:点认领,这个红人就归你负责,出现在 **MY KOL · 我负责的**。

**MY KOL 页面**分三块看你的资产:
- **公司官方账号矩阵** —— 自家平台号的发帖、播放、互动、异常提醒。
- **我负责的 KOL** —— 你认领的人,可加联系方式、标跟进状态、加入项目、看合作历史。
- **收藏/待跟进** —— 还在观望的人。

## 三、做项目(Projects · 项目跟进)

一个项目 = 一次和红人的完整合作,从寄样到发布复盘。

**开一个项目:**
1. 进 **Projects**,新建项目:填项目名、产品(SKU)、平台、目标发布日。
2. 从 KOL Pool / MY KOL **选红人进项目**。
3. 项目按阶段往前走:`确认 → 寄样发货 → 运输中 → 已签收 → 内容制作 → 已发布 → 发布后观测 → 复盘`。

**推进项目:**
- 在项目详情里登记 **物流单号**,签收后系统会进入观测窗口。
- **履约待办(due-list)** 在 Projects 首页:告诉你「该催发货/已签收未发布/已发布未复盘」的项目,照着做就行。
- 费用(运费/样品/合同款)、合同、发票、复盘都在项目详情各 Tab 里登记,健康度和 ROI 自动算。

**管理员派活:**
- 员工默认只看**自己负责或自己创建**的项目。
- 管理员在项目详情头部「**指派给…**」选员工,这个项目就归他,他随即在自己列表里看到。

## 四、办活动(Events · 活动)

线下展会 / KOL 见面会 / 媒体活动的执行台。

**建一个活动:**
1. 进 **Events**,新建活动:填标题、类型、时间、地点(可填经纬度,会上仪表盘地图)、预算。
2. **团队成员**:多选真员工,**第一个 = 负责人**。
3. 关联项目(可选)。

**活动详情里干活(都真存库,刷新还在):**
- **概览** —— 活动基本盘 + 健康度。
- **任务** —— 加任务、指派负责人、加协作人、勾完成、清单项。
- **预算+费用** —— 记每笔花费(类别、谁付的、报销状态)。
- **参与 KOL** —— 邀请红人参加、看确认状态。
- **物料 / 现场 / 复盘** —— 物料准备、现场 checklist、活动后复盘。

## 常见问题

- **我怎么什么项目都看不到?** → 你还没被派活。让管理员在项目里「指派给」你,或你自己新建项目。
- **搜完没反应?** → 看左侧任务卡 + 「最近历史」状态(查找中/已完成/未完成);失败会写明原因。
- **想要更多页面/数据权限?** → 找管理员在「系统设置 · 账号授权」给你的账号开对应权限。
- **页面和管理层长得一样?** → 对,大家用同一套界面,只是数据各看各的。
